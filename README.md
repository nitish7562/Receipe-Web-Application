# Receipe-Web-Application

# Find Meal For Your Ingredient 🍽️

A simple web application that helps you find meal recipes based on the ingredients you have.

## Features
- Search for recipes by ingredients.
- Fetch data from a meal API.
- Responsive UI with HTML, CSS, and JavaScript.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **API:** Edamam (API used)
- **Styling:** CSS
